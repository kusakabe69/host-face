# host-face（ホスフェイス）

複数店舗のスタッフの「顔 ↔ 名前」を暗記するための、静的Webの暗記クイズアプリ。

## 特徴
- 店舗を選んで、その店だけで練習（進捗も店舗ごとに保存）
- 写真を見て名前を6択で回答。正解はテンポよく自動で次へ、不正解は答え合わせで確認
- 苦手な人・未出題の人を重点的に出題（直近に出た人はしばらく出さない）
- 「やめる」まで無限に出題。連続正解・正解/不正解数を表示
- 習得状況画面：覚えた割合、出題人数・正解率、苦手な人、全員の成績
- スマホ最優先のレイアウト。進捗はブラウザの localStorage に保存

## 構成
- `index.html` / `app.js` / `style.css` … アプリ本体
- `stores.json` … 店舗＋スタッフのデータ（`photos` は各人の写真ファイル名の配列）
- `images/<店舗id>/<slug>/...` … 写真
- `download_images.py` … 写真取得とデータ生成用スクリプト

## ローカルで動かす
```
python -m http.server 8000
```
ブラウザで http://localhost:8000 を開く。

## 公開
GitHub Pages で配信。パスはすべて相対なのでサブパス配信でもそのまま動作します。
